# Mammography-only clinical rules

Текущий MVP Kompas ограничен маммографией. КТ и рентгенография не участвуют в rule engine и extraction prompt.

## Источники, по которым правила верифицированы

- КР 117_3 «Менопауза и климактерическое состояние у женщины» (2025): страницы 17-18, 39, 41, 69-70.
- КР 379_4 «Рак молочной железы» (2021): страницы 29-30, 80.
- КР 547_3 «Рак яичников / рак маточной трубы / первичный рак брюшины» (2024): страница 24.
- КР 858_1 «Воспалительные заболевания молочных желез» (2024): страницы 20, 25.
- КР 893_1 «Опухоли невыявленной первичной локализации» (2024): страница 17.

## КР 598_3

КР 598_3 «Доброкачественная дисплазия молочной железы» указана в продуктовой модели, но PDF не был передан в набор исходников. Поэтому в `clinical_sources.json` она помечена `source_pdf_missing`, `enabled=false`, и правила из нее не активируются.

В частности, мы НЕ кодируем на основании памяти/пересказа правило «BI-RADS 3 -> контроль через 6 месяцев» до проверки исходной КР 598_3.

## JSON-файлы

- `app/rules/clinical_sources.json` — реестр КР и статус верификации источника.
- `app/rules/mammography_rules.json` — условия срабатывания правил.
- `app/rules/steps.json` — действия, тексты и ссылки на конкретные КР/разделы/страницы.

## Принципы

1. BI-RADS и ACR хранятся отдельно.
2. Правая и левая молочная железа хранятся отдельно.
3. BI-RADS 4/5 не преобразуется в диагноз «рак».
4. Контекст воспалительного заболевания не запускает маммографию сам по себе: нужен признак отсутствия положительного эффекта лечения.
5. Если источник не подтверждает правило, оно не включается в engine.


## KR 598_3 verified
Uploaded KR 598_3 (2024) is now enabled. Implemented mammography-only rules include: screening age 40–75; mammography for nodular/palpable masses; ACR C/D handling; BI-RADS 0/1-2/3/4-5/6 routing; 6-month follow-up for BI-RADS 3; morphology/biopsy requirement for BI-RADS 4-5. BI-RADS and ACR remain separate per breast.
